## ✨ Features

- 💱 Convert between many international currencies
- 🔄 Swap source and target currencies instantly
- 🌍 Country flags update with the selected currency
- 📡 Uses the latest available exchange-rate data
- 🛟 Includes a fallback API endpoint if the primary request fails
- ✅ Validates the entered amount
- ⏳ Shows loading feedback while converting
- ⚠️ Displays a user-friendly message if the API request fails
- 📱 Responsive layout for desktop and mobile
- ♿ Improved labels and accessible form controls

---

## 🛠️ Built With

- **HTML5** — page structure and form elements
- **CSS3** — responsive styling and layout
- **JavaScript** — DOM manipulation, events, API calls, and conversion logic
- **Fetch API** — retrieving exchange-rate data
- **Font Awesome** — interface icons
- **[Currency API by Fawaz Ahmed](https://github.com/fawazahmed0/exchange-api)** — exchange-rate data
- **[FlagsAPI](https://flagsapi.com/)** — country flags

---

## ⚙️ How It Works

1. Enter an amount.
2. Select the currency you want to convert **from**.
3. Select the currency you want to convert **to**.
4. Press **Convert**.
5. The app fetches the latest available exchange rate and calculates the result.

You can also use the **swap button** to instantly reverse the selected currencies.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/CodexTalha/Currency-Converter.git
```

Move into the project folder:

```bash
cd Currency-Converter
```

Then open `index.html` in your browser, or use the **Live Server** extension in VS Code.
